# ACU — 針灸 × PNF 3D 輔助工具

### 🔗 線上直接打開：**[https://peterhsieh1119.github.io/ACU/](https://peterhsieh1119.github.io/ACU/)**

純靜態網頁的 3D 針灸／PNF 學習輔助：在同一個解剖模型上，把 **經絡穴位 ↔ 肌肉 ↔ PNF 對角模式** 三層資料接在一起，任一層都能點進去、互相跳轉。

## 功能

- **3D 人體**：可旋轉、縮放，體表透明度可調；前／後／左／右／頂視角一鍵切換
- **14 經絡 + 經外奇穴**：共 **210 個穴位**，可逐條經絡開關
- **穴位資訊**：定位、主治、刺法參考深度、特定穴屬性（原穴／絡穴／郄穴／募穴／背俞穴／八會穴／八脈交會穴…）、下方肌肉、相關 PNF 模式
- **肌肉層**：**90 條肌肉**，含起點、止點、作用與神經支配；可單獨顯示或整層透視
- **PNF 模式**：**20 個模式**（上肢／下肢 D1・D2、肩胛四模式、骨盆四模式、頭頸、砍劈與上舉），含動作組成、口訣、徒手接觸、臨床應用與常用技術
- **三向連結**：穴位 → 肌肉 → PNF，任一方向都能點擊跳轉
- **搜尋與篩選**：可用穴名、代號、主治關鍵字（如「頭痛」）搜尋，並依部位（頭面／頸項／胸部／腹部／背腰／下肢…）篩選，3D 模型會同步只留下符合的穴位
- **手機可用**：側欄改為抽屜、資訊卡從下方彈出，觸控點選有較寬的命中範圍
- **可分享連結**：選取狀態會寫進網址，例如 [`#p=LI4`](https://peterhsieh1119.github.io/ACU/#p=LI4)（合谷）、`#m=biceps`（肱二頭肌）、`#f=UE_D2F`（上肢 D2 屈曲）

## 操作

| 動作 | 效果 |
|---|---|
| 拖曳 / 滾輪 | 旋轉 / 縮放 |
| 點擊穴位或肌肉 | 顯示資訊並聚焦鏡頭 |
| `Esc` | 清除選取 |
| `↑` `↓` | 在目前篩選結果中切換上下一個穴位 |

## 本地執行

```bash
python -m http.server 8000
# 瀏覽器開 http://localhost:8000
```

ES module 需經 http 伺服器載入，直接雙擊 index.html 無法執行。three.js 由 CDN 載入，沒有建置步驟、沒有相依套件。

## 專案結構

| 檔案 | 內容 |
|---|---|
| `index.html` | 版面與樣式（響應式，桌機側欄／手機抽屜） |
| `js/geom.js` | 幾何工具：可變半徑 loft（`sweep`）與梭形錐度掃掠管（`tube`） |
| `js/body.js` | 人體模型：各部位剖面、體軸定義，以及把穴位吸附到體表的 `makeSnapper()` |
| `js/app.js` | 場景、互動、側欄、資訊面板、鏡頭運鏡與 URL 狀態 |
| `data/acupoints.js` | 15 組經絡定義、210 個穴位、經絡走行路徑 |
| `data/muscles.js` | 90 條肌肉的走行控制點、起止點、作用與神經支配 |
| `data/pnf.js` | 20 個 PNF 模式：動作組成、口訣、徒手接觸、臨床應用、主要肌肉成分 |

肌肉是三層資料的樞紐：`穴位.muscles` 與 `PNF模式.muscles` 共用同一組肌肉 id，三者之間的關聯由程式自動推得，不需要另外維護對照表。

## 實作重點

**穴位座標會自動貼合體表。** 資料裡的座標是依骨度分寸推算的近似值，載入時每個穴位都會從最近的體軸往外發射線、打到體表後再往外抬 5 mm，所以顯示位置比手填的數字更準，也保證看得見、點得到。經絡走行線也用同樣方式處理：長線段會先細分，每個補間點各自吸附一次，因此經絡會沿著身體表面走，而不是從身體內部穿過去。

**分層繪製決定遮蔽關係。** 繪製順序是「肌肉 → 皮膚 → 經絡線 → 穴位標記」，皮膚會寫入深度緩衝：位於身體另一側的穴位會被體表擋住（前視圖不會看到背俞穴），而體內的肌肉仍然透出來。

**座標系。** y 向上（身高 1.75 m）、+z 為身體前方、+x 為一側（雙側穴位只定義單側，程式自動鏡射）。主要骨架 landmark：肩 1.415｜肘 1.170｜腕 0.930｜髖 0.928｜膝 0.520｜踝 0.122｜臍 1.03｜C7 1.45｜頭心 1.63。這組數值是穴位資料的參考框架，改動會讓既有座標失準。

## 資料來源

- 穴位定位依 WHO Standard Acupuncture Point Locations 之通行定位描述
- PNF 肌肉成分整理自 Voss/Knott 傳統與《PNF in Practice》(Adler, Beckers & Buck)
- 穴位—肌肉對應依常用針灸解剖教材整理

## 免責聲明

本工具僅供解剖與經絡**學習參考**。3D 座標與肌肉幾何為示意近似，針刺深度為教科書常見參考值，皆不可作為臨床操作依據；「建議參考穴位」由肌肉交集自動推得，是選穴思路的提示而非治療處方。實際針灸請由合格中醫師執行，運動治療請由合格治療師評估後施行。
