# ACU — 針灸 × PNF 3D 輔助工具

### 🔗 線上直接打開：**[https://peterhsieh1119.github.io/ACU/](https://peterhsieh1119.github.io/ACU/)**

純靜態網頁的 3D 針灸／PNF 學習輔助：在同一個解剖模型上，把 **經絡穴位 ↔ 肌肉 ↔ PNF 對角模式** 三層資料接在一起，任一層都能點進去、互相跳轉。

## 功能

- **真實解剖模型**：體表、**79 組肌肉**與**131 件骨骼**取自 BodyParts3D 成年男性參考解剖（CC BY 4.0）
- **3D 人體**：可旋轉、縮放，體表透明度可調；前／後／左／右／頂視角一鍵切換；骨骼層可隨時疊上來對照骨性標誌
- **14 經絡 + 經外奇穴**：共 **210 個穴位**，可逐條經絡開關
- **穴位資訊**：定位、主治、刺法參考深度、特定穴屬性（原穴／絡穴／郄穴／募穴／背俞穴／八會穴／八脈交會穴…）、下方肌肉、相關 PNF 模式
- **肌肉層**：**90 條肌肉**，含起點、止點、作用與神經支配；可單獨顯示或整層透視
  （其中 79 條使用真實解剖網格，來源資料未收錄的 11 條——闊背肌、腹直肌、多裂肌、腰方肌與顏面肌群——以示意幾何表示並在面板標註）
- **PNF 模式**：**20 個模式**（上肢／下肢 D1・D2、肩胛四模式、骨盆四模式、頭頸、砍劈與上舉），含動作組成、口訣、徒手接觸、臨床應用與常用技術
- **三向連結**：穴位 → 肌肉 → PNF，任一方向都能點擊跳轉
- **搜尋與篩選**：可用穴名、代號、主治關鍵字（如「頭痛」）搜尋，並依部位（頭面／頸項／胸部／腹部／背腰／下肢…）篩選，3D 模型會同步只留下符合的穴位
- **手機可用**：側欄改為抽屜、資訊卡從下方彈出，觸控點選有較寬的命中範圍
- **可分享連結**：選取狀態會寫進網址，例如 [`#p=LI4`](https://peterhsieh1119.github.io/ACU/#p=LI4)（合谷）、`#m=biceps`（肱二頭肌）、`#f=UE_D2F`（上肢 D2 屈曲）

## 操作

| 動作 | 效果 |
|---|---|
| 拖曳 / 滾輪 | 旋轉 / 縮放 |
| 點擊穴位或肌肉 | 顯示資訊並聚焦鏡頭 |
| `Esc` | 清除選取 |
| `↑` `↓` | 在目前篩選結果中切換上下一個穴位 |

## 本地執行

```bash
python -m http.server 8000
# 瀏覽器開 http://localhost:8000
```

ES module 與解剖資產都需要經 http 伺服器載入，直接雙擊 index.html 無法執行。
three.js 由 CDN 載入；網頁本身沒有建置步驟，`npm install` 只有重新產生解剖資產時才需要。

## 專案結構

| 檔案 | 內容 |
|---|---|
| `index.html` | 版面與樣式（響應式，桌機側欄／手機抽屜） |
| `js/anatomy.js` | 解剖資產載入器（gzip 二進位 → BufferGeometry） |
| `js/retarget.js` | 把骨度分寸座標搬到真實解剖模型上 |
| `js/surfaceray.js` | 體表射線求交的加速結構（依高度分桶） |
| `js/geom.js` | 幾何工具：可變半徑 loft（`sweep`）與梭形錐度掃掠管（`tube`） |
| `js/body.js` | 內建示意人體模型，解剖資產載入失敗時的後備 |
| `scripts/build-anatomy.mjs` | 從 BodyParts3D 產生 `data/anatomy/` 的離線工具 |
| `data/anatomy/` | 體表、肌肉、骨骼幾何與骨架 landmark（約 2.5 MB，gzip） |
| `js/app.js` | 場景、互動、側欄、資訊面板、鏡頭運鏡與 URL 狀態 |
| `data/acupoints.js` | 15 組經絡定義、210 個穴位、經絡走行路徑 |
| `data/muscles.js` | 90 條肌肉的走行控制點、起止點、作用與神經支配 |
| `data/pnf.js` | 20 個 PNF 模式：動作組成、口訣、徒手接觸、臨床應用、主要肌肉成分 |

肌肉是三層資料的樞紐：`穴位.muscles` 與 `PNF模式.muscles` 共用同一組肌肉 id，三者之間的關聯由程式自動推得，不需要另外維護對照表。

## 實作重點

**穴位座標會 retarget 到真實骨架，再貼合體表。** 資料裡的座標是依骨度分寸推算的近似值，
其參考骨架與 BodyParts3D 不一樣（肘、腕、膝、踝差 3–6 公分），直接套用會整條經絡歪掉。
`js/retarget.js` 的作法是：在兩個模型上定義語意相同的體軸節點（肩→肘→腕→掌→指尖 等等），
求出穴位落在哪一段、段內比例與相對體軸的偏移方向，再到真實模型的同一段取新起點、
依兩段夾角旋轉偏移方向，最後射線打到真實體表。經絡走行線同樣處理：長線段先細分，
每個補間點各自投影，因此經絡貼著身體跑而不是從體內穿過去。

**背俞穴與督脈用真實椎體定位。** 這些穴位的定義是「第 n 椎棘突下、旁開幾寸」，
用比例映射會被真實背部的深度放大（膏肓會跑到肩胛骨外面）。程式改為直接取該節椎骨的
棘突位置，再用真實骨度分寸（肩胛骨內緣到後正中線＝3寸）算出側方距離。

**分層繪製決定遮蔽關係。** 繪製順序是「骨骼 → 肌肉 → 體表深度預繪 → 體表 → 經絡線 → 穴位標記」。
體表先只寫深度不上色，再單層著色：半透明的皮膚在腋下、指縫等處有多層前向面重疊，
直接畫會重複混色而出現斑駁。深度寫入也讓身體另一側的穴位被體表擋住（前視圖不會看到背俞穴），
而體內的肌肉與骨骼仍然透出來。

**載入失敗會自動退回內建示意模型。** 解剖資產抓不到或瀏覽器不支援 `DecompressionStream` 時，
`js/body.js` 會用可變半徑 loft 組出一具示意人體，穴位改用原本的骨度座標吸附，功能完全不受影響。

**座標系。** 公尺、y 向上、+z 為身體前方、+x 為受檢者左側（雙側穴位只定義單側，程式自動鏡射）。
真實模型身高 1.73 m；示意模型 1.75 m，主要 landmark：肩 1.415｜肘 1.170｜腕 0.930｜髖 0.928｜
膝 0.520｜踝 0.122｜臍 1.03｜C7 1.45｜頭心 1.63——這組數值是穴位資料的參考框架，改動會讓既有座標失準。

## 重建解剖資產

`data/anatomy/` 已經 commit 進 repo，一般不需要重跑。要重新產生：

```bash
npm install
git clone --depth 1 https://github.com/ashemag/human-atlas /tmp/human-atlas
npm run build:anatomy /tmp/human-atlas/public/models
```

## 免責聲明

本工具僅供解剖與經絡**學習參考**。BodyParts3D 是單一成年男性的參考解剖，不代表所有人的結構與變異；
穴位位置由骨度分寸推算後投影到該模型，是教學等級的近似而非個別化定位。針刺深度為教科書常見參考值，
皆不可作為臨床操作依據；「建議參考穴位」由肌肉交集自動推得，是選穴思路的提示而非治療處方。
實際針灸請由合格中醫師執行，運動治療請由合格治療師評估後施行。
